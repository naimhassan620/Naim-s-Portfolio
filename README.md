# Naim - Web Developer Portfolio

An interactive, responsive personal portfolio website showcasing web development projects, skills, and contact information with custom canvas animations.

## Features
- **Interactive Hero Animation**: Canvas-driven frame animation.
- **Projects Showcase**: Interactive cards detailing latest web applications.
- **Contact Form**: Built-in backend integration via `server.js`.
- **Responsive Design**: Optimized across mobile, tablet, and ultra-wide desktop displays.

## Getting Started

### Local Static Preview
Simply open `index.html` in your web browser.

### Running with Node.js Server
1. Run the local server:
   ```bash
   node server.js
   ```
2. Open your browser and navigate to `http://localhost:3000` (or specified port).
